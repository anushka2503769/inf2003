# INF2003 performance results (WP-10)

Generated by `bash backend/scripts/run_benchmark.sh` on 2026-10-26. Every number below was measured on throwaway local Docker databases seeded with synthetic data; nothing is estimated. See [README.md](README.md) for how to run it and how to read the tables.

## Machine and context

- CPU: Apple M5 (10 logical cores), RAM 32 GB
- OS: Darwin 25.5.0 (arm64)
- Docker Engine 29.8.0, Docker Desktop, 10 CPUs, 8319504384 bytes memory for containers
- PostgreSQL 16.15 (Debian 16.15-1.pgdg13+2) and MongoDB 7.0.45 in containers (postgres:16, mongo:7), default settings, no tuning
- Python 3.12.13, psycopg2 2.9.13, pymongo 4.18.1
- Timing: 3 warm-up calls, then 30 timed calls per row; median and p95 (linear interpolation) in milliseconds. Random seed 20261026.
